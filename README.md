# IPL Dashboard – Excel & Power BI

## Project Overview

This IPL Dashboard is developed using **Microsoft Excel and Power BI** to analyze Indian Premier League (IPL) match data and generate meaningful insights into team performance, player statistics, venue analysis, and match trends.

Excel is used for data preparation and cleaning, while Power BI is used to build an interactive dashboard with visualizations, charts, KPIs, and filters. The dashboard helps users explore cricket data and understand performance patterns across teams, players, and venues.

## Project Objectives

- Analyze IPL match data to identify team performance trends.
- Explore player statistics and individual performances.
- Compare team results across matches and seasons.
- Analyze venue-wise match trends.
- Create interactive visual reports for data-driven insights.

## Tools and Technologies

- **Microsoft Excel:** Data cleaning, formatting, and preparation.
- **Microsoft Power BI:** Dashboard development and data visualization.
- **Power Query:** Data transformation and preparation in Power BI.
- **DAX:** Measures and calculated metrics, where applicable.

## Dashboard Features

- **Team Performance Analysis:** Compare teams based on match results and performance metrics.
- **Player Statistics:** Analyze player contributions and performance.
- **Venue Analysis:** Explore match trends across different stadiums.
- **Season Analysis:** Review IPL trends across available seasons.
- **Interactive Filters:** Filter dashboard insights by season, team, player, or venue, depending on the available data.
- **Visual KPIs:** Present important metrics through cards, charts, and graphs.

## Project Workflow

1. Import IPL datasets into Microsoft Excel.
2. Clean and organize the data.
3. Load the prepared data into Power BI.
4. Transform and structure the data using Power Query.
5. Create measures and calculated metrics using DAX, where required.
6. Design interactive visuals and dashboard pages.
7. Analyze the results to identify meaningful insights.

## Key Learnings

- Data cleaning and preparation using Excel.
- Data transformation using Power Query.
- Creating interactive dashboards in Power BI.
- Data visualization and KPI development.
- Using DAX for calculations and analytical measures.
- Converting raw cricket data into meaningful insights.

## Business Value

The dashboard makes IPL data easier to explore and understand. It helps users compare team and player performance, identify venue-related trends, and analyze historical match results through interactive visualizations.

## Future Enhancements

- Add ball-by-ball analysis, if detailed data is available.
- Include advanced player performance metrics.
- Add season-over-season comparisons.
- Develop more detailed team comparison visuals.
- Incorporate additional KPIs and predictive analytics.

## Conclusion

The IPL Dashboard demonstrates how Excel and Power BI can be used together to transform raw cricket data into an interactive analytical report. It highlights practical skills in data preparation, visualization, dashboard design, and sports data analysis.
